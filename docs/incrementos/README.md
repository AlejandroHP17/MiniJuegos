# Incrementos

Registro de épicas e historias de usuario. Cada épica es una carpeta. `epica.md` es el mapa; cada historia tiene su propio archivo.

`docs/incrementos/<repo>/E01-<slug>/epica.md`

`docs/incrementos/<repo>/E01-<slug>/HU-1.md`

Estado de la épica: `abierta` (se puede actualizar), `en curso`, `cerrada` (solo si se pide cerrarla), `descartada` (el usuario la rechazó; no se implementa).

La foto de un juego ya hecho, sin épicas, vive en `docs/incrementos/<repo>/AS-IS.md` (`/sdd-foto`). No sustituye a las carpetas `E0N-*`.
